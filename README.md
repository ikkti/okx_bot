# OKX AI + Telegram
Deploy one Fly machine using Dockerfile and fly.toml. Set secrets DATABASE_URL, GROQ_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_ADMIN_ID, OKX_API_KEY, OKX_API_SECRET, OKX_PASSPHRASE. Optional ADMIN_PASSWORD enables existing web UI; ALLOW_LIVE=yes enables live mode; MAX_ORDER_USDT defaults to 10. Model fixed to openai/gpt-oss-120b. Use supplied database and Groq credentials as secrets, not in source. Rotate exposed credentials before production. Database creates only okx_ai_events. Supabase direct endpoint may require IPv6 or a session pooler connection string. Telegram private admin only. /start lists commands. /trade sends at most one order, /trade CONFIRM required in live mode. /stop does not close existing positions. Spot has no automatic stop loss. WebSocket freshness guard; candle analysis still uses REST. No latency guarantee. No live integration test performed. Use demo keys first. Single machine only; no distributed execution lock. No automatic retry of order submission. Check exchange order status after ambiguous failures.
